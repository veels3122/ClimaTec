5. Descripción del Dataset Inicial

Ecosistema de Datos Consolidado: El conjunto de datos integrado cumple con las métricas mínimas requeridas para el desarrollo del proyecto.
  • Volumen Total: Más de 10.000 registros consolidados.
  • Total de Variables: 10 variables estructuradas.
  • Variables Numéricas: temperatura_media, precipitacion_mm, emisiones_co2, anomalia_temp.
  • Variables Categóricas: pais, nivel_geografico, clasificacion_evento.
  • Variables Temporales: anio, fecha_registro.
  • Variables Geográficas: codigo_iso, departamento.
