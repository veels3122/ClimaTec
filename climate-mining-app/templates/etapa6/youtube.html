Conexión a la API

  1. En Google Cloud Console se creó un proyecto, se habilitó YouTube Data API v3 y se generó una clave de API.
  2. La clave se guarda como Secret de Colab o variable de entorno YOUTUBE_API_KEY; nunca en el código ni en el repositorio.
  3. scripts/youtube_extraccion.py llama a videos (metadatos públicos) y a commentThreads (100 por página, paginando con nextPageToken).
  4. Solo se guardan texto, fecha, likes y número de respuestas. No se guarda nombre, canal ni foto de los autores.

Restricciones: cuota diaria de 10.000 unidades (cada página cuesta 1); máximo 100 comentarios por página; solo comentarios públicos; los comentarios eliminados o retenidos por moderación no se descargan; las respuestas requieren otra llamada y no se incluyeron.

Reglas de scripts/youtube_limpieza.py: se eliminan vacíos y duplicados exactos (texto normalizado), comentarios sin palabras, con menos de 3 palabras (“primero”, “jajaja”) y spam con enlaces. Se borran URL y menciones del texto conservado, sin corregir ortografía para no alterar la opinión. El idioma se detecta por palabras vacías y se conserva solo el español, porque las stopwords y el sentimiento del flujo están en español.

Alcance

Las opiniones corresponden a quienes comentaron el video seleccionado: no representan a la población de ningún país ni a toda la audiencia. Sirven para generar hipótesis y contrastar percepciones, no para medir opinión pública.
